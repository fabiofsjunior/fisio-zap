# FisioZap MVP

## Objetivo
Provar que um assistente profissional reduz o trabalho operacional e mental de uma fisioterapeuta autônoma/domiciliar.

## Fluxo principal

1. Consultar a rotina do dia.
2. Ver notificações e pendências.
3. Abrir o contexto de um paciente.
4. Preparar o atendimento.
5. Registrar o atendimento por linguagem natural.
6. Gerar uma sugestão de evolução.
7. Revisar e confirmar.
8. Atualizar acompanhamento.

## Núcleos

- pacientes;
- agenda;
- atendimentos;
- evoluções;
- notificações;
- habilidades/exercícios/protocolos;
- assistente conversacional;
- financeiro básico.

## Fora do MVP

- emissão fiscal completa;
- marketplace;
- app exclusivo para paciente;
- automações de disparo em massa;
- gestão completa de clínicas;
- IA autônoma para decisão clínica.
